# YARG instrument rank artwork

All images in this folder are the original PNGs uploaded for the new instrument ranks; no pixels were changed when the filenames were standardized.

Five instruments: `guitar`, `bass`, `drums`, `keys`, `vocals`.

Each instrument uses these 10 files (replace `guitar` with its instrument name):

| Rank | Threshold | Filename |
| --- | ---: | --- |
| En bois | 1 | `guitar-01-wood.png` |
| Bronze | 5 | `guitar-02-bronze.png` |
| Argent | 15 | `guitar-03-silver.png` |
| Or | 25 | `guitar-04-gold.png` |
| Platine | 40 | `guitar-05-platinum.png` |
| Émeraude | 60 | `guitar-06-emerald.png` |
| Diamant | 90 | `guitar-07-diamond.png` |
| Maître | 120 | `guitar-08-master.png` |
| Grand Maître | 150 | `guitar-09-grand-master.png` |
| Champion | 200 | `guitar-10-champion.png` |

Unranked icon: `guitar-fallback.png` (same for other instruments).

Vocals also has `vocals-harmony-2.png` and `vocals-harmony-3.png`, used when the song chart offers two or three voices.

Catalogue: instrument medals appear only for a signed-in Rockstar who has met the corresponding performance threshold and has the title unlocked. Otherwise the fallback icon displays. Profile: badges reflect the same rank order.

Playlist artwork is in `assets/playlist-art/`, with `party-starters-rock.png`, `party-starters-pop.png`, `francophone.png`, `disney-pixar.png`, `videoclips.png`, and `fin-de-soiree.png`.
