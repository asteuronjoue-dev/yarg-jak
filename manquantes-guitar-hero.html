Comment interpréter les résultats ? « À vérifier » signifie que le titre existe dans ta bibliothèque, mais avec un artiste différent de la liste officielle (reprise, nom de groupe, erreur de données, etc.). Il ne faut pas le retélécharger sans vérifier. « Non trouvé » signifie qu’aucune correspondance simple n’a été identifiée; cela reste une liste de recherche, pas une preuve absolue d’absence. Le nombre affiché par ton filtre de jeux peut donc être inférieur au nombre de chansons réellement possédées.

Comment garder cette liste à jour ?

Quand tu remplaces songs.json sur GitHub et que GitHub Pages publie le changement, cette page recalcule automatiquement les chansons manquantes. Inutile de réexécuter l’action GitHub simplement pour ajouter des chansons à ta bibliothèque. En revanche, une correction des listes originales exige de regénérer official-game-setlists.json.

Les fichiers CSV sont en UTF-8, séparés par des points-virgules, avec un BOM pour Excel. Les chansons « À vérifier » sont séparées des absences probables. La liste dédoublonnée indique tous les jeux concernés.
