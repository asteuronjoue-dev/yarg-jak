🎸 Guitar Hero — Associer les chansons

Relie une chanson des listes originales à la bonne charte de ta bibliothèque YARG. Après publication des associations sur GitHub, elle apparaîtra dans les filtres des jeux pour tous tes invités.

Chargement des listes de jeux et du catalogue…

Comment ça fonctionne ?

  1. Dans À vérifier, clique 🔗 Associer une chanson.
  2. Recherche et sélectionne la vraie chanson dans ton catalogue (titre, artiste, album).
  3. Quand tu as terminé, clique ⬇ Télécharger game-song-matches.json, puis remplace le fichier de ce nom sur GitHub.
  4. Une fois le site publié, les invités retrouvent ces chansons dans les filtres de index.html.

Le bouton d'association enregistre un brouillon local. Seul le fichier game-song-matches.json publié sur GitHub change ce que voient les invités.
